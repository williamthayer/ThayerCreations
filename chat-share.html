Encrypted conversation

Your messages will appear here after the connection is ready.

Security note: Messages and file chunks use AES-256-GCM encryption, in addition to WebRTC's encrypted connection. Incoming files are automatically accepted from the person in the room. Files under 25 MB can be received without choosing a folder and downloaded from the chat; choose a save folder to stream larger files directly to disk. Without folder access, files are buffered in memory, so very large transfers depend on available memory. Only share the room code with someone you trust. The other peer and signaling service may see network connection metadata. This short code is for quick sharing, not highly sensitive information.
